# ILCYM_Predictor
To improve accessibility for plant health researchers through an interactive website called ILCYM Predictor, which allows users to choose validated pest or natural enemy models developed in ILCYM 4.0, thereby obtaining simulation graphs that describe the insect population and its risk factors in selected locations and time periods.
